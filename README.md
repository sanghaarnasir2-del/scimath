# SciMth — Advanced Scientific Calculator (PRO-991)

**SciMth** ek modern, high-precision scientific calculator web application hai jise customized design ke mutabiq banaya gaya hai:
- 📱 **Screen:** Pure White LCD Screen (Day aur Night dono modes me high readability).
- 🖤 **Body:** Sleek Matte Black Chassis (Jet Black finish, chamfered frame).
- 🔵 **Buttons:** Blue Keys (Day mode me Classic Sapphire & Royal Blue; Night mode me Cyber Glowing Neon Blue).
- 🌓 **Day / Night Mode Switch:** Header me ek click se Day aur Night mode switch hota hai.
- 📐 **Scientific Functions:** Trigonometry, Hyperbolic, Powers, Roots, Logarithms, Factorials, Deg/Rad angle switch, Memory registers, Calculation history aur Keyboard support.

## 🎛️ Functions & Controls

| Feature | Key / Button | Description |
|---|---|---|
| **Angle Mode** | `DEG` / `RAD` | Degrees aur Radians ke darmiyan switch karta hai |
| **2nd Function** | `2ⁿᵈ` | Inverse trig (`sin⁻¹`, `cos⁻¹`, `tan⁻¹`), `eˣ`, `10ˣ`, `∛x` enable karta hai |
| **Hyperbolic** | `hyp` | `sinh`, `cosh`, `tanh` enable karta hai |
| **Trigonometry** | `sin`, `cos`, `tan` | Sin, Cosine aur Tangent calculations |
| **Logarithms** | `ln`, `log` | Natural log ($ln$) aur Base-10 log ($log_{10}$) |
| **Powers & Roots** | `x²`, `x³`, `xʸ`, `√x`, `∛x`, `ʸ√x` | Powers aur roots calculate karne ke liye |
| **Constants** | `π`, `e` | Pi ($3.14159...$) aur Euler's constant ($2.71828...$) |
| **Combinatorics** | `n!` | Factorials ($5! = 120$) |
| **Memory** | `MC`, `MR`, `M+`, `M-` | Memory Clear, Recall, Add, Subtract |
| **History** | 🕒 (History Button) | Previous calculations ka drawer jo click par expression restore karta hai |
| **Day / Night** | ☀️ / 🌙 | Distinct Day aur Night blue theme toggling |

---

## ⌨️ Keyboard Shortcuts
- `0` - `9`: Numbers input
- `+`, `-`, `*`, `/`: Add, Subtract, Multiply, Divide
- `Enter` ya `=`: Calculate result
- `Backspace`: DEL (pichla number delete karein)
- `Escape`: AC (All Clear)
- `(` aur `)`: Brackets input
